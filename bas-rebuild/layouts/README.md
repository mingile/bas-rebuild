# AHU 배치 JSON

- `ahu-default.json`: 모든 건물의 모든 AHU가 쓰는 배치. AHU마다 다르게 하려면 `dataSource.getAhuLayout`에서 URL만 고른다.
- `assets.json`: 에셋 카탈로그. 키는 `assets/ahu/` 안의 파일 이름(확장자 제외), 값은 경로와 원본 크기.

## 형식

```
{ "canvas": { "width", "height" }, "items": [ ... ] }
```

좌표는 모두 canvas 기준 단위이고, 화면 크기에 맞춰 SVG가 비율대로 줄고 늘어난다. `items` 배열 순서가 그리는 순서(뒤에 있을수록 위)다.

| kind    | 필드                                                                   | 설명                                                                   |
| ------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `asset` | `asset`, `x`, `y`, `w`, `h?`, `rotate?`, `flipX?`, `point?`, `states?` | 에셋 이미지. `w`만 주면 비율대로, `w`·`h`를 모두 주면 그 크기로 늘린다 |
| `tag`   | `label`, `point`, `x`, `y`                                             | 포인트 이름과 현재 값 표시                                             |
| `label` | `text`, `x`, `y`                                                       | 고정 문구(공기 흐름 방향 등)                                           |

`point`는 연결할 포인트 이름이다. `states`는 값에 따라 에셋을 바꾸는 규칙으로, `min` 이상인 항목 중 마지막 것의 `asset`을 쓴다.
(예: 팬 `SF-S`가 0이면 `supply-fan`, 1 이상이면 `supply-fan-animated`)
`states`는 값 연결 단계에서 쓰며, 지금 화면은 `asset`에 적힌 기본 이미지만 그린다.
